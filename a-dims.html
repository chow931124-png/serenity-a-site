A 股特殊分析维度

美股没有的分析维度，新增适配 A 股市场的特有因子。北向资金、限售解禁、龙虎榜、融资融券——这些在 A 股的信号意义远强于美股。

🌊

1. 北向资金

重要先行信号

外资流入/流出趋势是 A 股 AI 板块的重要先行信号。连续 N>5 日净流入 = 外资认可，反之亦然。

数据源：同花顺北向（hgt 沪股通 + sgt 深股通分钟流向）
信号：连续净流入 → 板块底；连续净流出 → 需警惕
🔒

2. 限售解禁

供给冲击风险

原始股/定增股解禁对股价有短期冲击。解禁比例 > 总股本 10% 且流动性差 → 显著压力。

数据源：东财解禁日历
关键判断：解禁≠立刻减持，需看股东性质（PE/实控人/员工持股计划）
🐅

3. 龙虎榜机构席位

上涨性质判断器

机构买入 vs 游资买入，决定上涨的持续性。机构主导 = 趋势性，游资主导 = 脉冲。

数据源：东财龙虎榜席位
规则：机构净买 > 游资 → 可跟；纯游资 → 短线品种
⚖️

4. 融资融券

杠杆情绪温度计

融资余额趋势 = 杠杆资金情绪。融资余额持续上升 = 看多共识；融券激增 = 看空信号。

数据源：东财两融数据中心
注意：融资余额过高时也是反向指标（情绪过热）
🛑

5. 涨停板效应

A股特有现象

A 股 10%/20% 涨跌停限制会扭曲短期价格发现。连续涨停后的开板 = 短期情绪顶点。

判断：龙头首次开板可能是机会；跟风股连续涨停后开板 → 危险
红线：卡点≠短期交易信号，供应链卡点是 6-18 个月的结构性逻辑
📜

6. 政策驱动

A股最强催化

产业政策对 A 股板块的催化远强于美股。关键时点：两会/中央经济工作会议/工信部/科技部。

A 股经典节奏：政策底 → 市场底 → 业绩底
2026年关注：AI 政策/算力补贴/新质生产力
👤

7. 大股东/管理层行为

内部人信号

增持/回购/股权激励 = 信心信号。减持/质押 = 压力信号（需区分个人需求和公司经营）。

红旗：实控人持续减持（无论什么理由）→ 最大红旗之一
绿旗：高位增持+大额回购注销 → 真正有信心
📊

8. 筹码结构

聪明钱方向

股东户数连续下降 = 筹码从散到集。机构持股比例变化 = 聪明钱方向。

数据源：东财股东户数
判据：股东户数连续 3 季下降 + 机构增持 → 强烈信号

如何使用这些维度

📋

单股分析中：在估值之后、催化剂之前插入 A 股特殊维度分析。量化信号（北向/融资/股东户数变化）优先于定性判断。

赛道分析中：北向资金的整体流向比个股信号更可靠——看板块整体北向 vs 个股北向。

综合判定时：这些维度用于修正信念档——北向持续流入可上提一档，巨额解禁在即下压一档。

⚠️
不要过度解读短期信号。北向单日流出 / 涨停板打开 / 单日融资减少 都是噪音。关注趋势（3-5日/季度的方向），而不是单点。

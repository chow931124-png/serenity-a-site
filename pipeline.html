12 步分析流水线

从 Scope Gate 到独立复核，完整闭环的分析流程。每一步都有明确的输入、处理和输出。

① Scope Gate→ ② 锁周期+终端→ ③ 画供应链栈→ ④ 钻卡点→ ⑤ 判据→ ⑥ 红旗
⑦ 估值→ ⑧ 催化剂→ ⑨ 交叉验证→ ⑩ 美股映射→ ⑪ 综合判定→ ⑫ 独立复核

流程详解

Scope Gate — 范围界定

用户需求模糊时最多问 3 个短问题锁定范围：超级趋势 = AI 基础设施建设（任意细分都跑）；周期 = 6-18 个月；地域 = A 股。默认不追问 AI 赛道以外的话题。

锁周期 + 终端

它在这个 supercycle 的什么位置？落到具体的产品/技术路径：光模块 400G→800G→1.6T？算力 NVDA GB300 还是国产算力？机器人 Optimus 量产还是国产人形？只追结构性周期，不追单日新闻。

关键问题：这一层明天停产，下游要等多久恢复？

画供应链栈 + 多跳映射

画 5-9 层栈（终端 → 系统 → 模组 → 器件 → 芯片 → 材料/衬底），顺已知供货关系逐跳上溯。用 OSINT 线索（官网供应商增减/CFO 失言/生态 PPT/RFQ/投资 deck）推断未公开关系。

L6 终端 → L5 系统 → L4 模组 → L3 器件 → L2 芯片 → L1 衬底 → L0 原料
每一跳标证据等级：已证实 / OSINT 推断 / 推测

钻"卡点中的卡点"

继续往最底层钻：模组 → 器件 → 芯片 → 材料/原料。越往下越可能是 single point of failure。叠加地缘单卡（如中国控约 70% 的铟）= 材料 + 地缘双卡，最强卡点。

不能只看一层——InP 衬底既要铟（中国控~70%）又要高纯磷前驱体，两条独立垄断链各自是 single point of failure。

好卡点判据

用 14 条好卡点判据逐一核对当前标的/环节，命中越多信念越高。详见方法论页面。

红旗扫描

用 12 条红旗逐一扫描，命中即降级/否决。A 股特有红旗：大股东减持、解禁、监管风险、商誉过高。详见方法论页面。

估值

先判类型（高成长卡点型 / 周期反转型 / 深价值型）再套尺子，输出 Bear / Base / Bull 三档。含精度降级规则——含推断假设的区间降为"数量级/方向"。

催化剂时点

A 股催化剂清单：北向资金持续流入、机构调研频率、产业政策、财报季、大厂新品（GTC/OFC）、限售解禁前后、龙虎榜（游资/机构动向）、股东户数趋势。

证据交叉验证

数源分类：已证实 / 管理层声称 / 推断 / 推测。关键数据必须有一手源（10-K/10-Q/公告），聚合站/博客只作线索。多源交叉：公司财报 > 行业数据 > 产业报道 > 卖方研报 > 社交贴。

美股→A股映射分析（按需/自动）

当分析涉及 AI/半导体/光通信等全球供应链共通的板块时自动激活。分析四维度：情绪映射（短）、估值锚定（中）、订单传导（长）、竞争格局（不定期）。

综合判定

值不值得 = 卡点强度 × 错杀程度 × 证据成色 × 催化剂时点 × 红旗 × 所处周期。

方向性定档：Strong Buy / Buy / Hold / Sell。（A 股不设 Fire Sale，因受涨跌停限制）

独立复核（必做，不可跳过）

给用户最终回复之前，派独立 reviewer（全新上下文，sub-agent 模式）挑刺：查取数、查逻辑、查偏误、查发现、查可读性。裁决 pass / revise。无 sub-agent 环境降级：显式说明 + 联网重核 ≥3 关键数字 + 标 [未独立复核]。
